# Zentry Clone

A modern, animation‑rich frontend clone inspired by the **Zentry award‑winning website**. This project focuses on smooth interactions, high‑performance animations, and a clean UI/UX using **React**, **Vite**, **Tailwind CSS**, and **GSAP**.

---

## 🚀 Live Preview
- Weblink:- [Link](https://zentry-clone-coral.vercel.app/)

---

## 🚀 Tech Stack

* **React (with Vite)** – Fast development & optimized builds
* **JavaScript (ES6+)** – Core logic and interactions
* **Tailwind CSS** – UI development
* **GSAP** – High‑performance animations

---

## 🎯 Features

* Smooth, fluid animations
* Scroll‑based animations
* Modern UI inspired by an award‑winning design
* Fully responsive layout
